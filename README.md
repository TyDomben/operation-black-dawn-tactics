# Operation Black Dawn

A deep tactical squad combat game inspired by XCOM, featuring turn-based tactical combat, base management, and a full campaign mode.

## Features

### Core Gameplay
- Turn-based tactical combat on grid maps
- Command 4-6 squad members per mission
- Destructible environments
- Cover system (half cover, full cover)
- Overwatch and reaction shots
- Flanking bonuses and positioning tactics

### Campaign Mode
- 20 story missions with increasing difficulty
- Base management between missions
- Research tech tree (40+ upgrades)
- Build/upgrade facilities in your base
- Recruit and train soldiers
- Manage resources (money, intel, supplies)
- Time-sensitive missions
- Strategic layer with world map
- Multiple endings based on choices

### Soldier System
8 Classes with full skill trees:
1. **Assault** - Close combat, shotguns
2. **Sniper** - Long range, precision
3. **Heavy** - Suppression, explosives
4. **Medic** - Healing, support
5. **Engineer** - Traps, turrets, hacking
6. **Scout** - Stealth, recon, mobility
7. **Psionic** - Mind powers, support
8. **Specialist** - Versatile, jack-of-all-trades

Features:
- Level 1-10 progression
- 8-10 abilities per class with choices
- Stat growth (HP, Aim, Will, Dodge)
- Customizable appearance
- Personality traits
- Bonds between soldiers
- Permadeath
- Will/morale system

### Equipment
- 30+ weapon types (rifles, shotguns, snipers, SMGs, LMGs, rockets, melee)
- 10+ armor tiers (light, medium, heavy, special)
- 40+ items (grenades, medkits, ammo types, gadgets, consumables)
- Weapon attachments and upgrades

### Enemies
4 Factions with 50+ enemy types:
1. **Terrorist Cells** - Human enemies, varied tactics
2. **Rogue Military** - Advanced weapons, armor
3. **Alien Invaders** - Exotic abilities, technology
4. **Robots/Mechs** - Tough, predictable, hackable

AI Behaviors:
- Flanking attempts
- Use of cover
- Suppression and grenades
- Coordinate attacks
- Retreat when wounded
- Call reinforcements

### Mission Types
15 different objectives:
- Elimination, Extraction, Sabotage
- Defend, Hack, Escort
- Ambush, Stealth, Capture
- Bomb Defusal, Terror Mission
- Base Assault, Supply Raid
- Assassination, Survival

### Base Management
Facilities:
- Power Generator, Barracks, Research Lab
- Engineering Bay, Infirmary, Training Center
- Psi Lab, Proving Grounds, Resistance Comms
- Workshop, Defense Matrix

Resources:
- Money, Intel, Supplies, Alien Materials, Elerium

### Technical Features
- Save/Load system with multiple slots
- Ironman mode (autosave, permadeath)
- Statistics tracking
- Modding-friendly JSON data

## How to Play

1. Open `index.html` in a modern web browser
2. Click "NEW CAMPAIGN" to start
3. Choose your difficulty and settings
4. Manage your base and research new technologies
5. Select missions and deploy your squad
6. Complete objectives while minimizing casualties
7. Level up soldiers and unlock new abilities

### Controls
- **Left Click** - Select unit / Move / Attack
- **Right Click** - Cancel action / Context action
- **1-8** - Ability hotkeys
- **Enter** - End turn
- **Tab** - Next unit
- **Q/E** - Rotate camera
- **Z/X** - Zoom in/out
- **Escape** - Pause menu

## Requirements

- Modern web browser with JavaScript enabled
- HTML5 Canvas support
